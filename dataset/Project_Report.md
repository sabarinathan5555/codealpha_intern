# Project Report: Handwritten Character Recognition using CNN

## Objective
Recognize handwritten digits from image data using image processing and deep learning.

## Dataset
The demonstration uses the scikit-learn digits dataset with 1,797 grayscale images at 8×8 resolution. An optional MNIST 28×28 dataset path is included in the notebook.

## Methodology
1. Load labeled images.
2. Normalize pixel values.
3. Split into training and testing subsets.
4. Build and train a CNN.
5. Evaluate test accuracy and classification metrics.
6. Plot training accuracy and a confusion matrix.
7. Predict a test image.

## Conclusion
This project provides an end-to-end starter for handwritten digit recognition. Alphabet and full-word recognition are possible extensions using EMNIST and sequence models such as CRNN.
